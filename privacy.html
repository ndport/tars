Privacy policy

TARS · effective 8 November 2026

What data TARS accesses

With the owner's explicit consent through Google sign-in, TARS accesses the owner's Google Calendar events, Google Tasks and, when enabled, read-only content of Google Drive files and Google Docs that the owner links in calendar events.

How the data is used

  • Only to show, create, update and complete the owner's own events and tasks, and to read documents the owner links to them.
  • Data is processed on the owner's own server. It is not sold, not shared with third parties, not used for advertising and not used to train AI models.
  • TARS does not create events with guests or send invitations or emails unless the owner explicitly asks for it.

Storage and security

Access tokens are stored encrypted on the owner's server and are never published or written to code repositories. TARS keeps no separate copy of calendar or task data beyond what is needed to complete a request.

Google API Services User Data Policy

TARS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke TARS's access at any time at myaccount.google.com/permissions.

Contact

Questions: github.com/ndport/tars/issues.

По-русски

С согласия владельца TARS получает доступ к его событиям Google Календаря, Google Задачам и (если включено) к чтению файлов Google Диска и Документов, приложенных к событиям. Данные используются только для работы с делами самого владельца, обрабатываются на его сервере, не продаются, не передаются третьим лицам, не используются для рекламы и обучения моделей. Мероприятия с гостями и письма — только по прямой просьбе владельца. Токены хранятся зашифрованными на сервере владельца. Отозвать доступ: myaccount.google.com/permissions.
